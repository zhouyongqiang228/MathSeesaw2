# MathSeesaw2 浙教版开发计划 - 工程整理

## 当前工程模块

- `GameBootstrap.cs`：关卡启动入口。负责读取关卡数据、绑定场景引用、初始化跷跷板、小人和 UI。正式场景应优先使用 Unity 手工编辑对象。
- `LevelController.cs`：核心玩法控制。负责拖拽、吸附、计分、胜利判定、跷跷板数量切换和相机取景。
- `Blance.cs`：单个跷跷板控制。负责左右盘引用、座位数量配置、重量变化后的旋转。
- `NumContainerPan.cs`：左右盘容器。负责座位列表、总分统计、座位启用/禁用布局。
- `ManPlace.cs`：单个座位。负责小人放置、锁定、隐藏/显示和高亮反馈。
- `PutMan.cs`：可拖拽数字小人。负责数字显示、倍率计算、初始状态恢复和胜利动作。
- `GameUI.cs`：游戏内 UI。负责关卡进度、单/双跷跷板切换、重玩、菜单、胜利面板。
- `LevelDatabase.cs`：关卡数据。后续浙教版真实关卡应优先进入这里。
- `GameManager.cs` / `GameProgressManager.cs` / `AudioManager.cs` / `HapticManager.cs`：全局流程、进度、音频、震动。
- `MainMenu.cs`：主菜单和关卡选择。当前脚本存在，但还需要配套 `MainMenu.unity` 和 Build Settings。

## 已完成调整

1. 降级运行时代码创建场景
   - `GameBootstrap` 默认不再自动创建相机、灯光、环境、跷跷板、小人。
   - 如果场景引用缺失且未开启 `allowRuntimeSceneFallback`，会报错并停止初始化，避免覆盖 Unity 手工场景。
   - 旧的生成逻辑保留为 `Build Editable Scene Fallback` Context Menu，仅作为开发兜底工具。

2. 跷跷板左右座位数量可配置
   - `Blance` 新增 `leftSeatCount` / `rightSeatCount`。
   - `NumContainerPan.ApplySeatCount` 会按数量显示、锁定和重新排布座位。
   - `ManPlace` 新增运行时可用状态，多余座位不会参与吸附、计分和胜利展示。

3. 支持 1 个或 2 个跷跷板
   - `LevelController.activeSeesawCount` 根据 `SeesawMode.Single/Double` 自动切换。
   - 切换时只激活需要的跷跷板，保留场景中原始摆放位置。

4. 相机根据跷跷板数量自动设置视角
   - `LevelController` 新增单/双跷跷板相机位置、旋转、基础 orthographic size。
   - `frameActiveSeesaws` 开启时，会根据当前激活跷跷板的渲染边界自动扩大取景。
   - 保留移动端宽屏/窄屏响应式 size 修正。

## 下一步开发清单

- 在 Unity 中检查 `Game.unity` 的 `GameBootstrap.allowRuntimeSceneFallback` 为关闭状态。
- 在每个 `Blance` 组件中按关卡需求设置 `leftSeatCount` / `rightSeatCount`。
- 关掉当前 Unity 实例后，运行 batchmode 编译检查。
- 创建 `MainMenu.unity`，并把 `MainMenu` 和 `Game` 加入 Build Settings。
- 创建并绑定 `LevelDatabase.asset`，用浙教版真实关卡替换默认数据。
- 将跷跷板和环境拆成 prefab，减少场景手工维护成本。
