## Unity 项目设置步骤

### 1. 创建场景
需要创建以下场景：

#### a. MainMenu 场景
```
1. 创建空场景：Assets/Scenes/MainMenu.unity
2. 添加空物体，命名为 "MainMenuManager"
3. 挂载 MainMenu.cs 脚本
4. 保存场景
```

#### b. Game 场景（已存在，需要更新）
```
在已有的 Game 场景中：
1. 确保有 GameBootstrap 组件
2. 添加 LevelDatabase ScriptableObject 引用
```

### 2. 创建 ScriptableObject

#### 创建 LevelDatabase
```
1. 右键点击 Assets 文件夹
2. Create > MathSeesaw > Level Database
3. 命名为 "LevelDatabase"
4. 在 Inspector 中点击 "Create Default Levels" 按钮（需要在脚本中添加这个编辑器按钮）
5. 将这个 ScriptableObject 拖到 GameBootstrap 的 levelDatabase 字段
```

### 3. 创建管理器预制体

#### a. GameManager Prefab
```
1. 创建空物体，命名 "GameManager"
2. 挂载 GameManager 脚本
3. 拖到 Resources 文件夹创建预制体
4. 在第一个加载的场景中放置一个实例
```

#### b. AudioManager Prefab
```
1. 创建空物体，命名 "AudioManager"
2. 挂载 AudioManager 脚本
3. 添加 2 个 AudioSource 组件
4. 在未来添加音频文件到 Resources/Audio/
```

```
1. File > Build Settings
2. 添加场景（按顺序）：
   - MainMenu
   - Game
3. 选择平台：iOS 或 Android
```

## iOS 原生插件（触觉反馈）

需要创建 iOS 插件来支持触觉反馈。

### 创建文件：Assets/Plugins/iOS/HapticFeedback.mm

```objective-c
#import <Foundation/Foundation.h>
#import <UIKit/UIKit.h>

extern "C" {
    void _TriggerImpactFeedback(int style) {
        if (@available(iOS 10.0, *)) {
            UIImpactFeedbackStyle feedbackStyle;
            switch (style) {
                case 0: feedbackStyle = UIImpactFeedbackStyleLight; break;
                case 1: feedbackStyle = UIImpactFeedbackStyleMedium; break;
                case 2: feedbackStyle = UIImpactFeedbackStyleHeavy; break;
                default: feedbackStyle = UIImpactFeedbackStyleMedium; break;
            }
            UIImpactFeedbackGenerator *generator = [[UIImpactFeedbackGenerator alloc] initWithStyle:feedbackStyle];
            [generator impactOccurred];
        }
    }
    
    void _TriggerNotificationFeedback(int type) {
        if (@available(iOS 10.0, *)) {
            UINotificationFeedbackType feedbackType;
            switch (type) {
                case 0: feedbackType = UINotificationFeedbackTypeSuccess; break;
                case 1: feedbackType = UINotificationFeedbackTypeWarning; break;
                case 2: feedbackType = UINotificationFeedbackTypeError; break;
                default: feedbackType = UINotificationFeedbackTypeSuccess; break;
            }
            UINotificationFeedbackGenerator *generator = [[UINotificationFeedbackGenerator alloc] init];
            [generator notificationOccurred:feedbackType];
        }
    }
    
    void _TriggerSelectionFeedback() {
        if (@available(iOS 10.0, *)) {
            UISelectionFeedbackGenerator *generator = [[UISelectionFeedbackGenerator alloc] init];
            [generator selectionChanged];
        }
    }
}
```
