# MathSeesaw2 - 快速设置指南 ⚡

> 跟随这个指南，10分钟内让游戏跑起来！

## 第一步：创建场景 (2分钟)

### 1. 创建 MainMenu 场景
```
1. File > New Scene
2. 删除默认的 Main Camera 和 Directional Light
3. 创建空物体：GameObject > Create Empty
4. 命名为 "MainMenuRoot"
5. 添加组件：Add Component > Main Menu
6. File > Save As > Assets/Scenes/MainMenu.unity
```

### 2. 配置 Build Settings
```
1. File > Build Settings
2. 点击 "Add Open Scenes" 添加 MainMenu
3. 打开 Game 场景
4. 点击 "Add Open Scenes" 添加 Game
5. 确保 MainMenu 在列表最上面（索引 0）
```

## 第二步：创建 LevelDatabase (2分钟)

### 1. 创建 ScriptableObject
```
1. 在 Project 窗口，右键 Assets 文件夹
2. Create > MathSeesaw > Level Database
3. 命名为 "LevelDatabase"
4. 选中这个文件
5. 在 Inspector 中点击 "Create Default Levels" 按钮
6. 看到 "Created 20 default levels" 消息
```

### 2. 连接到 GameBootstrap
```
1. 打开 Game 场景
2. 找到 GameBootstrap 对象
3. 将 LevelDatabase 拖到 GameBootstrap 的 "Level Database" 字段
4. 保存场景 (Ctrl+S / Cmd+S)
```

## 第三步：创建管理器 (2分钟)

### 选项 A：快速方式（推荐）
```
1. 在 MainMenu 场景中
2. GameObject > Create Empty
3. 命名为 "GameManager"
4. Add Component > Game Manager
5. 保存场景

注意：其他管理器会自动创建
```

### 选项 B：手动方式
```
为每个管理器重复以下步骤：
1. GameObject > Create Empty
2. 命名为对应的管理器名称
3. 添加对应的组件：
   - GameManager
   - GameProgressManager  
   - AudioManager
   - MobileInputManager
   - HapticManager
```

## 第四步：测试游戏 (2分钟)

### 1. 测试 MainMenu 场景
```
1. 打开 MainMenu 场景
2. 点击 Play 按钮
3. 应该看到：
   - "MATH SEESAW" 标题
   - START GAME 按钮
   - LEVEL SELECT 按钮
   - SETTINGS 按钮
4. 点击各个按钮测试导航
```

### 2. 测试 Game 场景
```
1. 打开 Game 场景
2. 点击 Play 按钮
3. 应该看到：
   - 跷跷板和小人
   - 左上角的 1/2 切换按钮
   - 顶部进度条
   - 右上角的 R 和 M 按钮
4. 测试拖放小人
5. 点击 "2" 按钮切换到双跷跷板
```

## 第五步：配置项目设置 (2分钟)

### 1. Player Settings
```
1. Edit > Project Settings > Player
2. Company Name: [你的公司名]
3. Product Name: Math Seesaw
4. Version: 1.0.0
```

### 2. 分辨率设置
```
在 Player Settings > Resolution and Presentation:
1. Default Orientation: Portrait
2. Allowed Orientations: Portrait (只勾选这个)
3. 取消勾选 Use Animated Autorotation
```

### 3. 图标（可选，稍后准备）
```
在 Player Settings > Icon:
1. 拖入 1024x1024 的图标
2. Unity 会自动生成各种尺寸
```

## 常见问题排查 🔧

### 问题 1: 找不到 "Create > MathSeesaw > Level Database"
```
解决：
1. 检查 LevelDatabase.cs 是否有编译错误
2. 确保文件中有 [CreateAssetMenu] 属性
3. 重启 Unity 编辑器
```

### 问题 2: 点击 Play 后黑屏
```
解决：
1. 检查 Console 是否有错误
2. 确保场景中有 Main Camera
3. 确保 GameBootstrap 在 Game 场景中
4. 确保 MainMenu 组件在 MainMenu 场景中
```

### 问题 3: 按钮点击没反应
```
解决：
1. 确保场景中有 EventSystem
2. 检查 Canvas 的 Render Mode 是否为 Screen Space - Overlay
3. 检查按钮是否有 Button 组件
```

### 问题 4: LevelDatabase 字段找不到
```
解决：
1. 确保 GameBootstrap.cs 已正确更新
2. 保存所有脚本
3. 回到 Unity 等待编译完成
4. 刷新 Inspector
```

### 问题 5: 小人拖不动
```
解决：
1. 确保小人有 Collider 组件
2. 确保 Camera 正确设置
3. 检查 LevelController 是否正确初始化
```

## 优化建议 🚀

### 性能优化
```
1. Edit > Project Settings > Quality
2. 选择适合移动端的质量级别
3. 减少阴影质量（如果有）
4. 关闭不必要的后处理效果
```

### 内存优化
```
1. 压缩纹理
2. 使用对象池（如果创建大量对象）
3. 及时清理不用的资源
```

### 启动优化
```
1. 减少启动场景的复杂度
2. 异步加载资源
3. 延迟初始化非关键系统
```
