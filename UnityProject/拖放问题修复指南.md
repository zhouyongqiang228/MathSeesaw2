# 拖放问题修复和预览功能实现指南

## 已实现的改进

### 1. 输入系统改进 ✅
修改了 `LevelController.cs` 的 Update 方法，使用更可靠的输入检测：

**问题诊断：**
- 原代码使用 `Pointer.current`，在某些情况下可能不稳定
- 松开检测可能不准确

**解决方案：**
- 优先检测触摸输入（`Touchscreen.current`）
- 回退到鼠标输入（`Mouse.current`）
- 明确检测 `wasPressedThisFrame` 和 `wasReleasedThisFrame`

### 2. 半透明预览功能 ✅
添加了放置预览系统，显示小人将被放置的位置：

**新增功能：**
- 拖动小人时，在可放置位置显示半透明预览
- 预览会跟随鼠标/手指移动到最近的空座位
- 松开后预览消失

**实现方式：**
- 创建 `PlacementPreview.cs` 辅助类
- 在 `LevelController.cs` 中集成预览系统
- 使用半透明材质（透明度 30%）

### 3. 调试工具 ✅
创建了 `InputDebugger.cs` 帮助诊断输入问题：

**功能：**
- 实时显示输入状态（触摸、鼠标、Pointer）
- 显示 LevelController 状态
- 按 F1 键切换显示/隐藏

## 快速修复步骤

### 步骤 1：更新场景（2分钟）

在 **Game 场景**中添加 InputDebugger：

```
1. 打开 Game 场景
2. 创建空物体：GameObject > Create Empty
3. 命名为 "InputDebugger"
4. Add Component > Input Debugger
5. 保存场景
```

### 步骤 2：测试输入（1分钟）

```
1. 运行游戏（Play）
2. 按 F1 键显示调试信息
3. 观察输入状态：
   - 点击屏幕时，是否显示 "Pressed: True"
   - 松开时，是否显示 "Just Released: True"
4. 如果没有反应，说明输入系统有问题
```

### 步骤 3：检查物理碰撞（2分钟）

小人无法拾取的常见原因是缺少 Collider：

```
1. 在 Hierarchy 中找到一个 PutMan 小人
2. 在 Inspector 中检查：
   ✓ 是否有 BoxCollider 或其他 Collider 组件
   ✓ Collider 是否启用（勾选）
   ✓ Layer 是否正确（Default 或自定义）
3. 如果没有 Collider：
   - 选中小人
   - Add Component > Box Collider
   - 调整 Size 和 Center 包围小人
```

### 步骤 4：检查相机设置（1分钟）

```
1. 选中 Main Camera
2. 检查 Inspector：
   ✓ Camera 组件启用
   ✓ Culling Mask 包含小人的 Layer
   ✓ 位置和角度正确
```

### 步骤 5：测试拖放（2分钟）

```
1. 运行游戏
2. 点击小人：
   - 调试信息应显示 "Just Pressed: True"
   - 小人应该变大并可以移动
3. 拖到跷跷板附近：
   - 座位应该高亮（变白色/变大）
   - 应该看到半透明的预览小人
4. 松开：
   - 调试信息应显示 "Just Released: True"
   - 小人应该跳到座位上
```

## 常见问题排查

### 问题 1: 点击没反应
**可能原因：**
- UI 挡住了点击（EventSystem 拦截）
- 小人没有 Collider
- 输入系统未初始化

**解决方案：**
```csharp
// 在 LevelController.Update() 开始处添加日志：
Debug.Log($"Pressed: {pressed}, JustPressed: {justPressed}, JustReleased: {justReleased}");
```

### 问题 2: 可以拖动，但无法松开
**可能原因：**
- `wasReleasedThisFrame` 未触发
- 拖动过程中物体被销毁

**解决方案：**
```csharp
// 在 Drop() 开始处添加日志：
void Drop()
{
    Debug.Log($"Drop called! DragMan: {m_dragMan}, HoverPlace: {m_hoverPlace}");
    // ... 其余代码
}
```

### 问题 3: 无法放到跷跷板上
**可能原因：**
- `snapDistance` 太小
- 座位没有正确初始化
- `FindNearestEmptyPlace` 没有找到座位

**解决方案：**
```
1. 在 LevelController Inspector 中：
   - 增大 Snap Distance（试试 3.0 或 5.0）
2. 在 DragMove() 中添加日志：
   Debug.Log($"Hover Place: {(place != null ? place.name : "null")}");
```

### 问题 4: 预览不显示
**可能原因：**
- 材质创建失败
- 预览对象被隐藏

**解决方案：**
```
1. 检查 Console 是否有材质相关错误
2. 在 UpdatePreviewGhost() 中添加日志：
   Debug.Log($"Preview: {(m_previewGhost != null ? "Created" : "Null")}, Active: {(m_previewGhost?.activeSelf ?? false)}");
```

## 性能优化建议

### 如果拖动卡顿：

```csharp
// 在 LevelController 中添加：
[Header("Performance")]
public int physicsIterations = 1;

void Update()
{
    // 减少物理计算频率
    Physics.autoSimulation = false;
    for (int i = 0; i < physicsIterations; i++)
    {
        Physics.Simulate(Time.deltaTime);
    }
    
    // ... 其余代码
}
```

### 如果预览创建慢：

```csharp
// 使用对象池预创建预览
void Start()
{
    // 预创建所有预览
    foreach (var man in putMans)
    {
        var preview = CreatePreviewGhost(man);
        preview.SetActive(false);
    }
}
```
