# 双跷跷板功能实现说明

## 功能概述
为 MathSeesaw2 游戏添加了双跷跷板模式支持，玩家可以在游戏界面顶部左侧的按钮切换 1 个或 2 个跷跷板。

## 已实现的功能

### 1. 新增文件
- `SeesawMode.cs` - 定义跷跷板模式枚举 (Single/Double)
- `SeesawConfig.cs` - 跷跷板配置类（暂时保留，未来可扩展）

### 2. 修改的文件

#### GameBootstrap.cs
- 添加 `seesawMode` 字段，可在 Inspector 中选择模式
- 修改 `BuildSeesaw` 方法为 `BuildSeesaws`，支持创建多个跷跷板
- 新增 `BuildSeesaw(Vector3 offset, int index)` 方法，支持在指定位置创建跷跷板
- 单跷跷板位置：中心 (0, -0.6, 1.2)
- 双跷跷板位置：
  - 左侧：(-4, -0.6, 1.2)
  - 右侧：(4, -0.6, 1.2)

#### LevelController.cs
- 将 `Blance blance` 改为 `List<Blance> seesaws`，支持多个跷跷板
- 移除 `leftPan` 和 `rightPan` 直接引用（通过 seesaws 访问）
- 添加相机配置：
  - 单跷跷板：位置 (0, 3.4, -9.5), 旋转 (13, 0, 0)
  - 双跷跷板：位置 (0, 5.5, -12), 旋转 (18, 0, 0)
- 新增 `SwitchSeesawMode(SeesawMode mode)` 方法，切换跷跷板模式
- 新增 `ApplyCameraSettings()` 方法，应用相机设置
- 更新 `FindNearestEmptyPlace` 遍历所有激活的跷跷板
- 更新 `UpdateScore` 处理所有激活的跷跷板
- 更新 `CheckAndDealGameOver` 检查所有激活跷跷板的平衡状态

#### GameUI.cs
- `Build` 方法新增参数：`SeesawMode currentMode` 和 `Action<SeesawMode> onModeChanged`
- 新增 `BuildSeesawModeToggle` 方法，在左上角创建模式切换按钮
- 按钮样式：
  - 激活状态：高亮青色 (0, 0.9, 1)，白色文字
  - 未激活状态：灰色 (0.7, 0.7, 0.7)，深灰色文字 (0.3, 0.3, 0.3)
- 新增 `SwitchMode` 方法，处理模式切换并更新按钮状态

## 使用方法

### 在 Unity Editor 中
1. 打开 Game 场景
2. 在 Hierarchy 中找到 GameBootstrap 对象
3. 在 Inspector 中找到 `Seesaw Mode` 字段
4. 选择 `Single` (1个) 或 `Double` (2个)
5. 运行游戏

### 运行时切换
1. 游戏启动后，左上角会显示模式切换按钮（标记为 "1" 和 "2"）
2. 点击 "1" 按钮显示单个跷跷板
3. 点击 "2" 按钮显示两个跷跷板
4. 切换时会自动调整相机视角和位置

## 技术细节

### 跷跷板管理
- 使用 `List<Blance> seesaws` 管理所有跷跷板
- 模式切换时通过 `SetActive` 控制跷跷板显示/隐藏
- 单跷跷板模式只激活第一个跷跷板
- 双跷跷板模式激活所有跷跷板

### 相机调整
- 双跷跷板模式：相机拉远拉高，俯视角度增大，确保两个跷跷板都在视野内
- 单跷跷板模式：相机位置和原来保持一致

### 游戏胜利条件
- 所有激活的跷跷板都必须平衡
- 所有小人都必须被放置
- 满足以上条件时触发胜利

## 未来可扩展的功能
1. 为不同关卡配置不同的跷跷板布局
2. 支持 3 个或更多跷跷板
3. 自定义每个跷跷板的位置和旋转
4. 不同跷跷板使用不同的皮肤样式
5. 跷跷板之间的交互逻辑（如连锁反应）

## 注意事项
- 确保场景中有足够的小人来填充所有跷跷板的座位
- 双跷跷板模式下，游戏难度会增加，需要平衡更多的位置
- 相机参数可能需要根据实际场景调整以获得最佳视觉效果
